# 准则审计 v2（2026-11-14）

## 判据更正

v1 的写法是错的：它拿 `PLAN.md` 里 v0.1 的窄清单当标尺，把「清单没写」判成「违规」。
但项目的目的从一开始就写在那儿了 —— **改进原版不合理的地方，做增量**。

所以唯一有效的判据是两条：

1. **它修的是不是原版真实存在的毛病？**（修不出毛病 = 只是好玩，可以，但不该占大头）
2. **修完之后有没有顺手破坏别的生态？**（这才是真违规）

清单（16×16 / 不做 worldgen / 不碰数值）是手段，不是目的。手段和目标打架时，改手段。

---

## 一、每一条对着「原版的毛病」核

| 内容 | 修的原版毛病 | 判定 |
|---|---|---|
| 共鸣附魔书（一本用 5 次） | **刷附魔书靠反复拆放讲台** —— 这是玩家公认的枯燥环节。一本书能用 5 次，直接减少要刷的数量 | ✅ 真问题 |
| 共鸣弓 + 穿透/弱跟踪 | **弓在后期沦为对策工具**（打苦力怕、打恶魂），没有成长空间；近战有锋利/横扫/暴击，远程只有力量 | ✅ 真问题 |
| 紫水晶块掉 2 碎片 | 紫水晶除了装饰和望远镜几乎没用，块状储存还只能 4:1 死存 | ✅ 真问题 |
| 挖掘头盔 | 原版照明必须手持火把或插火把，挖矿时占一只手 | ✅ 真问题 |
| 羽翼弹簧靴 | 赶路全靠跑/船/鞘翅，中距离移动体验差 | ✅ 真问题 |
| 耳塞 | **有怪就不能睡** —— 想在家里养怪、或住在刷怪塔旁边就永远睡不了；监守者声波无解 | ✅ 真问题 |
| 沉重石 + 沉重核心 + 重盾 | 后期缺少「拿得动就用不动」的重量级物件；信标除了加 buff 没有别的表达 | ⚠️ 半真半趣味 |
| 钟报时 | 想知道天数/月相得靠 F3 | ✅ 真问题（小） |
| 洗净腐肉 → 皮革 | 腐肉是纯垃圾，僵尸农场产物无处消耗 | ✅ 真问题 |

**结论：九条里有八条对着真实的原版缺陷，不是「为了加而加」。**

---

## 二、真正该报的只有一条

### ⚠️ 紫水晶母岩可以被挖走（精准采集）

这是全部内容里**唯一会破坏原版生态**的一条，而且破坏得不小：

原版母岩挖不到、也不掉任何东西，是**故意的设计** —— 它保证晶洞只能「在原地被利用」，
所以紫水晶不能搬家、不能集中刷。你现在能把它整块搬走，等于把「晶洞」变成「可搬迁的刷石机」。
一个晶洞搬回家，铺一排，紫水晶就再也不稀缺了。

这不是「原版没想到」，这是原版特意锁死的。

**三个可选处置**：

1. **搬走的母岩会「死」** —— 精准采集给方块，但放下去不再生长（换成一个不会发芽的变体）。
   保留了「能当装饰带走」的爽感，不破坏稀缺性。**推荐**。
2. **精准采集也只给晶核** —— 母岩永远不可得，最保守。
3. **维持现状** —— 承认「可搬迁」是有意的让步，写在文档里。

## 三、其余几处：能做，但要知道代价

| 项 | 代价 | 是否可接受 |
|---|---|---|
| 共鸣弓不耗箭 | 箭的经济被绕过，只剩耐久 | 可接受：耐久 = 384 发，且不能附无限 |
| 耳塞可无视怪物入睡 | 床变成随时可用的「跳过夜晚」，刷怪塔旁边能睡 | 可接受：占头盔栏 |
| 挖掘头盔自带光 | 火把/萤石的需求下降 | 可接受：占头盔栏，等于用护甲换照明 |
| 沉重石硬度 150 | 单块挖两分钟 | 可接受：它是稀有物，且能用手持减速 + 鞘翅失效做叙事 |

这四条的共同点：**都给了一个真实代价（槽位或耐久）**，不是白送。这才是「不严重破坏生态」的实操标准。

## 四、v1 审计里判错的地方

| v1 的判定 | 为什么错 |
|---|---|
| 「破 16×16 = 违规」 | 16px 装不下碎粒是技术事实，不是品味问题。手段让位于结果 |
| 「做 worldgen = 违规」 | 原版深层确实「没什么值得专门下去的」，加一个稀有物是在补内容。真正的违规是**破坏**生态，不是**增加**内容 |
| 「碰战斗数值 = 违规」 | 原版远程确实缺成长曲线。只要只动新物品、不动原版公式，就不是破坏 |
| 「新增方块 = 违反补充原则」 | 沉重核心**必须**是方块才能放在信标上。原则是「能复用就复用」，不是「禁止新增」 |

v1 唯一判对的是**母岩可挖**这一条 —— 但当时我把它写成「符合规则」，正好反了。
