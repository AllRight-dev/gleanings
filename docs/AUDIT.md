# 准则审计（2026-11-14）

对照 `PLAN.md` 的三条铁律 + 补充原则 + 不做清单，逐条核。

结论先说：**三条铁律守住了主体，补充原则破了 2 条，不做清单破了 2 条。**

---

## 一、三条铁律

### 铁律 1：不浮夸（贴图 16×16、不发光；学习成本 ≤ 2 次右键）

| 判据 | 现状 | 判定 |
|---|---|---|
| 不发光 / 无装饰性粒子 | 全部无发光；粒子只有拉弓蓄能，且已从视线中心挪到准星下方 | ✅ |
| **贴图 16×16** | `resonance_dregs` `mining_helmet` `heavy_shield` `winged_boots` **都是 32×32** | ❌ **破了 4 张** |
| 学习成本 ≤ 2 次右键 | 头盔/耳塞/靴子 = 0–1 次；沉重石 = 挖/手持；**共鸣书链 = 晶核→合成台→铁砧→铁砧，4 步** | ⚠️ 一处超 |

破 16×16 的理由是真的：384→16 的碎渣试过三种采样全是糊的。但规则写死的是 16×16，不能一边破一边说没破。

### 铁律 2：不突兀（不新增实体、不新增世界观词汇）

| 判据 | 现状 | 判定 |
|---|---|---|
| 不新增实体 | 声波是射线 + 原版粒子/音效，没有新实体 | ✅ |
| 不新增世界观词汇 | 新增了「共鸣」一个词族（晶核/残渣/弦/附魔书/弓）和「沉重威压」 | ⚠️ 边界 |
| 玩家会以为原版一直有 | 紫水晶=共鸣、监守者声波、信标、铁砧、附魔书 —— 全在原版语义里 | ✅ |

「共鸣」挂在紫水晶的物理语义（校准幽匿感测体用紫水晶碎片）上，不是凭空造词。但确实是新词。

### 铁律 3：有用（必须挂在已存在的原版机制上）

逐条核对，无一例外：

| 内容 | 挂靠的原版机制 |
|---|---|
| 洗净腐肉 → 皮革 | 炼药锅 + 烟熏炉 + 皮革经济 |
| 钟报时 | 原版钟 + 月相/天气 |
| 晶核 | 母岩掉落 + 精准采集取舍 |
| 残渣 / 共鸣书 | 铁砧 + 附魔书 + 耐久条 |
| 共鸣弦 | 回响碎片（远古城市）+ 线 |
| 共鸣弓 | 原版弓 + 铁砧（保附魔）+ 监守者声波 |
| 耳塞 | 睡眠判定 + 头盔栏 + `sonic_boom` 伤害类型 |
| 挖掘头盔 | 原版 `minecraft:light` 方块 |
| 沉重石 | `FallingBlock` + 铁砧伤害公式 + 属性修饰符 |
| 沉重核心 | 信标 + `BeaconBeamBlock` 接口 |
| 重盾 | `LivingIncomingDamageEvent` + 原版格挡语义 |
| 羽翼靴 | `STEP_HEIGHT` / `JUMP_STRENGTH` 属性 |

唯一不算「挂靠」的是沉重石的**世界生成** —— 它不挂机制，它是新内容。判 ⚠️。

## 二、补充原则

| 原则 | 现状 | 判定 |
|---|---|---|
| **能用原版方块承载的机制，绝不新增方块** | 新增了 2 个方块：沉重石、沉重核心 | ⚠️ 有理由（核心必须可放置到信标上；沉重石本身就必须是方块才能下坠） |
| **优先数据驱动，少碰 Mixin** | 4 个 mixin（铁砧/睡眠/…），worldgen 与 loot 全为 JSON | ⚠️ mixin 数量超预期 |

Mixin 清单：`AnvilMenuMixin`（书不被吞）、`ServerPlayerSleepMixin`（耳塞入睡）。两个都无可替代 —— 原版没有对应事件。

## 三、不做清单（问题最重的部分）

`PLAN.md` 第 48 行原文：**「不做：…worldgen、任何 GUI」**
同文件第 6 段的隐含前提还包括「不碰战斗数值」。

| 清单项 | 现状 | 判定 |
|---|---|---|
| 不新增矿石 / 装备等级 / 维度 | 无 | ✅ |
| 不新增怪物 | 无 | ✅ |
| **不做 worldgen** | **沉重石有 configured_feature + placed_feature + biome_modifier** | ❌ **破了** |
| 不做 GUI | 无 GUI | ✅ |
| 不做任务书 | 无 | ✅ |
| **不碰战斗数值** | 共鸣弓伤害 6–12；穿透/弱跟踪附魔；重盾免格挡；音波 −40% | ❌ **破了** |

**世界生成这条是我自己写的理由最硬的一条**：「不可逆、和别的 mod 打架、删了存档留坑」—— 然后我加了。加的时候没提这一句，这是审计要抓的东西。

---

## 四、还有一处不违反字面、但违反精神的

**共鸣弓不消耗箭 + 射线贯穿。** 规则里没写「不许比原版强」，但「不浮夸」的精神指向平衡。现状是：造一把共鸣弓 = 永久免箭远程 + 直线全穿透。

这不是规则问题，是**设计债**。要么改规则承认它强，要么给它加成本（比如强制消耗残渣当弹药）。

---

## 五、处置建议

规则是 v0.1 时定的，那时计划里只有「洗腐肉 + 钟」。后续的装备、世界生成、战斗效果，本质上越过了那份窄清单。

两条路：

**A. 改规则（推荐）** —— 承认它已经长成一个「小型 content mod」，把准则升级到 v0.3：

```
铁律 1 修订：贴图 16×16 为默认；细节密集的物品（碎粒、装备）允许 32×32，
             但同一 mod 内不得超过 1/3 的物品是 32px。
铁律 3 补充：允许新增方块，条件是「它必须是方块才能工作」（可放置/可下坠）。
不做清单修订：
  - worldgen 允许，但只允许「替换已有方块、极低概率、不新增结构、不改群系」。
  - 战斗数值允许，但只允许「新物品自带」，不修改原版物品与公式。
```

**B. 回退内容** —— 删 worldgen、删战斗装备（共鸣弓/重盾/附魔），回到「缝隙填补」。

按你实际的兴趣走向，A 更贴近你真正在做的东西。
