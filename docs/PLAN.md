# 拾遗 Gleanings — 项目计划（已锁定）

> 目标：一个**贴合原版**的 Minecraft 1.21.1 NeoForge 扩充 mod。
> 附带目标：在做它的过程中，把「怎么用 AI 干活」练熟。交付物是两个：mod 本体 + 本目录下的经验集。

---

## 一、三条铁律（所有需求都拿这三条过）

1. **不浮夸** —— 贴图 16×16、不发光、不加装饰性粒子；一个功能的学习成本 ≤ 2 次右键。
2. **不突兀** —— 不新增实体，不新增世界观词汇；玩家第一次遇到它，会以为原版一直有。
3. **有用** —— 必须挂在一个**已存在的原版机制**上（书与笔、睡觉、交易、炼药锅、钟）。挂不上的不要。

补充原则（由上面推出来）：

- **能用原版方块承载的机制，绝不新增方块。** 新方块是最后手段。
- **优先数据驱动**（配方 / loot / 数据组件 / 配置），少碰 Mixin、GUI、自定义渲染 —— 那些是「AI 会非常自信地写错，然后你要陪它 debug」的区域。

## 二、验收清单（每次交付前逐条过）

- [ ] 贴图没有超出 16×16 主色域，没有发光
- [ ] 没有新增实体
- [ ] 所有新机制都指向一个原版方块 / 物品 / 事件
- [ ] `en_us` 和 `zh_cn` 都有
- [ ] 资源路径全小写 snake_case
- [ ] CI 绿（`build/libs/*.jar` 非空）
- [ ] jar 里 `assets/` `data/` `META-INF/neoforge.mods.toml` 齐全
- [ ] **装进实例，能进世界，`latest.log` 无 `Missing texture` / `Unable to load` / 注册表报错**

## 四、v0.1 范围（当前版本）

| 功能 | 载体 | 状态 |
|---|---|---|
| 钟报时：右键钟显示天数 / 时刻 / 月相 / 天气 | 原版钟，零新方块 | ✅ 已实现 |
| 炼药锅洗腐肉 → 洗净的腐肉 → 烟熏炉 → 皮革 | 原版炼药锅 + 烟熏炉 | ✅ 已实现 |

**不做**（进 parked，等能力升级再加难度）：边缘放置（要 Mixin）、淘洗砂砾、蛛丝纺线、烤甜菜、命名牌、生物行为、worldgen、任何 GUI。

## 五、路线图

- **v0.1 通电**（本版）：骨架 + CI + 两个功能 → 验证「写 → CI → 装 → 进世界」闭环。
- **v0.2 手感**：边缘放置（首次引入 Mixin，单独一版趟风险）。
- **v0.3 缝隙**：炼药锅淘洗砂砾、蛛丝纺线，做成配置可关。
- **v0.4 平衡**：按玩家反馈调配方，补成就（advancement）和进度引导。
- **v0.5 发布**：Modrinth 页面、图标、README、兼容性声明。

## 六、协作模式（B + C）

- **B 学徒式**：每轮给 2–3 个决策点 + 推荐 + 代价，产品方向由 YG 拍板。
- **C 翻车式**：AI 不确定的地方当场说「我猜的，等 CI 判」，红了就一起看。技术细节由 AI 自己定，不反复问。
- 每次翻车写进 `AI-LOG.md`，可复用的做法写进 `EXPERIENCE.md`。
