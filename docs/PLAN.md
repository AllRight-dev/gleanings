# 拾遗 Gleanings — 项目计划（已锁定）

> 目标：一个**贴合原版**的 Minecraft 1.21.1 NeoForge 扩充 mod。
> 附带目标：在做它的过程中，把「怎么用 AI 干活」练熟。交付物是两个：mod 本体 + 本目录下的经验集。

---

## 一、判据（v0.3 修订：目的优先，清单退位）

**目标**：改进原版里不合理的地方，做增量。不是加东西，是补窟窿。

任何新内容只问两句话：

1. **它修的是原版真实存在的毛病吗？**
   修不出来（纯装饰、纯好玩）也可以留，但**不该占大头**。
   例：刷书靠拆讲台、弓只能当对策、有怪不能睡、挖矿占一只手、中距离赶路没手段。

2. **修完之后有没有顺手破坏别的生态？**
   这才是真违规。判据是「有没有给真实代价」—— 占槽位、耗耐久、要稀有材料。
   白送的能力一律砍掉或补代价。

原先那三条（不浮夸 / 不突兀 / 有用）仍然有效，但降级为**风格指导**：

- **不浮夸** —— 默认 16×16；细节装不下的（碎粒、装备）允许 32×32，但不超过物品总数的 1/3。
- **不突兀** —— 不新增实体；新词挂在原版语义上（紫水晶=共鸣、监守者=声波）。
- **有用** —— 每个机制必须指向一个原版方块 / 物品 / 事件。

手段层面的允许范围（v0.3）：

- worldgen：允许「替换已有方块、极低概率、不新增结构、不改群系」。
- 战斗数值：允许「新物品自带」，**不修改原版物品与公式**。
- 新方块：只在「它必须是方块才能工作」时新增（可放置 / 可下坠 / 可被信标识别）。
- 不做：新矿石、新维度、新怪、GUI、任务书、修改原版物品属性。

## 五、路线图

- **v0.1 通电**（本版）：骨架 + CI + 两个功能 → 验证「写 → CI → 装 → 进世界」闭环。
- **v0.2 手感**：边缘放置（首次引入 Mixin，单独一版趟风险）。
- **v0.3 缝隙**：炼药锅淘洗砂砾、蛛丝纺线，做成配置可关。
- **v0.4 平衡**：按玩家反馈调配方，补成就（advancement）和进度引导。
- **v0.5 发布**：Modrinth 页面、图标、README、兼容性声明。

## 六、协作模式（B + C）

- **B 学徒式**：每轮给 2–3 个决策点 + 推荐 + 代价，产品方向由 YG 拍板。
- **C 翻车式**：AI 不确定的地方当场说「我猜的，等 CI 判」，红了就一起看。技术细节由 AI 自己定，不反复问。
- 每次翻车写进 `AI-LOG.md`，可复用的做法写进 `EXPERIENCE.md`。
